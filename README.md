# SFWatchfaceSDK
## 1. 集成

### 1.1 Swift Package
```bash
https://github.com/OpenSiFli/SFWatchfaceSDK_iOS.git
https://github.com/OpenSiFli/SifliOCore.git
```

```java
import SFWatchfaceSDK
import SifliOCore
```
版本号匹配

- SFWatchfaceSDK 1.0.3
- SifliOCore 1.0.12


### 1.2 CocoaPod

```bash
  pod 'SifliOCore','1.0.12'
  pod 'SFWatchfaceSDK','1.0.3'
```
